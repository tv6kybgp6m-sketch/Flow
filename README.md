# 记账本 Bookkeeping

简洁美观的记账应用，支持 macOS / iPhone 使用。

## 功能

- 收支记录、分类管理、预算管理
- 报表分析：点击「总收入 / 总支出 / 净结余」卡片钻取对应指标，支持折线图、柱状图、饼图（饼图标注分类名称与占比），趋势可按日 / 按月 / 按年切换，点击分类或图表可查看每笔流水
- Excel 导入导出
- PWA 离线使用
- iCloud 数据同步

## 技术栈

HTML + CSS + JavaScript + Chart.js + SheetJS
